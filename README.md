# 🚀 DevStore — Landing Page Oficial (Grupo GT1)

> **"Tu ecosistema tecnológico integral: Hardware, Software y Cursos en un solo lugar."**

Marketplace especializado en tecnología que unifica la compra de hardware de desarrollo, herramientas y licencias digitales, y cursos prácticos de programación en una única plataforma accesible y optimizada.

---

## 🛠️ Stack Tecnológico

- **Build Tool:** [Vite 6.x](https://vitejs.dev/)
- **Core:** Vanilla JavaScript (ES6+ modular)
- **Estilos:** [Tailwind CSS 3.4](https://tailwindcss.com/) + PostCSS + Autoprefixer
- **Iconografía:** [Lucide Icons](https://lucide.dev/) (con tree-shaking optimizado)
- **Tipografía:** [Inter](https://fonts.google.com/specimen/Inter) + [JetBrains Mono](https://fonts.google.com/specimen/JetBrains+Mono)

## 💻 Instrucciones para Ejecución Local

Para levantar el entorno de desarrollo:

```bash
# Entrar al directorio del proyecto
cd "C:\Users\omar lazaro\.gemini\antigravity-ide\scratch\devstore-landing"

# Ejecutar el servidor de desarrollo
npm run dev
```

El servidor estará disponible en `http://localhost:3000` (o el puerto indicado en la consola).

### Compilar para Producción

```bash
npm run build
```

Genera los archivos optimizados listos para producción en la carpeta `dist/`.

### Probar el Bundle de Producción

```bash
npm run preview
```
